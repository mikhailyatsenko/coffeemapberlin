## Question

How should the map behave when a visitor opens it from a Place page via "Show location on the map"?

## Answer

Today it returns to the full map with every Place marker showing, which buries the one the visitor cared about. Instead: show only that Place's marker (every other marker hidden) and open its brief card immediately, so the visitor lands straight on the thing they clicked through for. Decided directly by the user during the map's charting session; no further grilling needed.
